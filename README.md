##Livraria_FESO

A Livraria é uma plataforma onde **usuários podem navegar pelo catálogo, favoritar livros, adicioná-los ao carrinho, realizar pedidos e avaliar suas leituras**.

O sistema também possui um fluxo para autores. **Um usuário pode se tornar autor e enviar uma solicitação para uma editora, propondo a publicação de um livro**. A editora analisa a solicitação e, caso aprove, o livro é publicado na plataforma e fica disponível para compra.

Os livros são vendidos para os usuários, enquanto as editoras ficam responsáveis por sua publicação e gerenciamento. Caso uma editora decida retirar um livro da plataforma, ele não é apagado de fato: fica apenas inativo, preservando o histórico de pedidos e avaliações.

**A ideia do projeto é simular, de forma simples, o funcionamento de uma livraria online, desde a publicação de um livro até sua compra pelo cliente.**
