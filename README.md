📖 Sobre o projeto

A Livraria_FESO é uma plataforma de livraria online desenvolvida para simular o funcionamento de um ambiente de comércio literário, conectando leitores, autores e editoras em um único sistema.

Por meio da plataforma, os usuários podem explorar um catálogo de livros, descobrir novas histórias e gerenciar suas próprias experiências de leitura.

✨ Funcionalidades
👤 Para usuários
🔎 Navegar e pesquisar pelo catálogo de livros.
❤️ Favoritar livros de seu interesse.
🛒 Adicionar livros ao carrinho.
📦 Realizar pedidos e acompanhar suas compras.
⭐ Avaliar livros e compartilhar opiniões.
✍️ Para autores
📝 Solicitar a publicação de livros.
📚 Enviar propostas para editoras cadastradas.
📋 Acompanhar o status das solicitações de publicação.
🏢 Para editoras
📩 Receber e analisar solicitações de publicação.
✅ Aprovar ou recusar propostas de autores.
📖 Publicar livros aprovados na plataforma.
📦 Gerenciar o estoque e os livros publicados.
🔒 Desativar livros sem perder seu histórico.
🔄 Fluxo de publicação

O processo de publicação de um livro acontece em algumas etapas:

O usuário se cadastra e pode se tornar autor.
O autor envia uma solicitação de publicação para uma editora.
A editora analisa a proposta recebida.
A editora aprova ou recusa a solicitação.
Caso seja aprovada, o livro é cadastrado e disponibilizado no catálogo.
Os usuários podem visualizar e comprar o livro.
📚 Gerenciamento de livros

Um dos cuidados do sistema é preservar o histórico das operações.

Quando uma editora decide retirar um livro da plataforma, ele não é excluído permanentemente. Seu cadastro apenas recebe o status de inativo.

Dessa forma, são preservados:

O histórico de pedidos.
As avaliações realizadas pelos usuários.
As informações de publicação.
Os relacionamentos com autores e editoras.
🎯 Objetivo do projeto

O objetivo da Livraria_FESO é desenvolver uma aplicação que represente, de maneira simples e organizada, o funcionamento de uma livraria digital.

O projeto contempla diferentes perfis de usuários e seus respectivos processos, desde a solicitação de publicação de uma obra até sua comercialização e avaliação pelos leitores.
